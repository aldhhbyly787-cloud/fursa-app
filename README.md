# فُرصة - Fursa

منصة عراقية للتواصل المباشر بين أصحاب العمل والباحثين عن عمل.

## الهوية البصرية
- اللون الأساسي: الأسود
- اللون المميز: الذهبي
- لغة التطبيق الأساسية: العربية
- اتجاه الكتابة: من اليمين إلى اليسار

## المنصات
- تطبيق الباحثين عن عمل
- تطبيق أصحاب العمل
- تطبيق الإدارة الخاص

## التقنية المستهدفة
Flutter
